# 🗺️ Facility Finder Chemnitz

**An interactive map-based web application built with Django REST Framework and Next.js to help users discover childcare and educational facilities in Chemnitz.**

This project was developed as part of the *Databases and Web Techniques* course at **TU Chemnitz**. It visualizes open data using map-based filtering and geolocation features, helping citizens and organizations easily locate key public services.

---

## 📌 Features

- 🔐 User registration, login (JWT authentication)
- 🧭 Map with real-time filtering by category
- 📍 Display facilities from multiple open datasets
- 🌍 Geolocation using OpenCage API
- ⭐ Favorite facility selection and profile display
- 🧾 Swagger API documentation
- 📊 PostgreSQL database
- 🧪 Clean, RESTful API structure with Django REST Framework

---

## 🛠 Tech Stack

| Layer     | Technology               |
|-----------|---------------------------|
| Backend   | Django, Django REST Framework |
| Frontend  | Next.js (React)           |
| Database  | PostgreSQL                |
| Auth      | JWT                       |
| Geocoding | OpenCage API              |
| Docs      | Swagger (drf-yasg)        |

---

## 🧠 Project Motivation

The application addresses a real-world need to locate education and care facilities across Chemnitz using public open data. It provides an intuitive interface for families, social workers, and organizations to find suitable services and manage preferences.
